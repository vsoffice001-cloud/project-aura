## Severe deviation flags
1. **DM Sans-as-display override** in `theme.css:193+442` — fights Noto Serif brand voice
2. **Off-brand purple `#7f5fe3`** saturates product: chart palette, loaders (5 spots), sort arrows, link underlines (~30+ refs) — reads as purple-themed product, not Ken-red brand
3. **`bg-[#6400E4]`** cobalt purple in `Footer.tsx:134` — pure off-brand, no token
4. **"MANDATORY" off-scale padding** baked in tokens: `px-[67.5px] lg:px-[90px]` and `px-[84.375px] lg:px-[112.5px]` — fractional Figma-artboard-derived values, not 4px/8pt grid
5. **Body color set to `--color-text-secondary` (gray 600)** + `p { opacity: 0.7 }` global → washed-out body text everywhere
6. **`html { scroll-behavior: smooth }`** fights Lenis
7. **`* { border-color: var(--color-border-default) }`** global — slow + breaks Tailwind
8. **`dot-pattern-bg` utility** references undefined CSS vars (broken at runtime)
9. **Glassmorphic hero card** + video bg + DIY rAF orb — cinematic-dark visuals on editorial-light page, no recipe basis
10. **Heading hierarchy broken** — many sections use `<p>` w/ large size instead of `<h2>` (a11y issue)

## DS LEARNINGS (from this audit, NEGATIVE space — what to PROTECT against)
1. **DS atom violations** — even local DS atoms hardcoded hex; canonical DS atoms must enforce tokens via TS-typed prop API + lint
2. **Multiple parallel DS sources** = catastrophic drift; canonical DS workspace must be sole truth
3. **Mandatory off-scale spacing in tokens** = anti-pattern; document spacing rules visibly
4. **DM Sans-as-display override** = brand voice drift; document Noto Serif as display invariant
5. **Purple chart palette deviation** = no chart palette in canonical DS = vacuum filled by ad-hoc
6. **Body opacity 0.7 + secondary text color** = compounding washing-out; document body type rules
7. **`html { scroll-behavior: smooth }` vs Lenis** — DS docs need Lenis-first directive
8. **Editorial-light section bg alternation drift** = recipe needs strong enforcement (lint? ESLint plugin?)
