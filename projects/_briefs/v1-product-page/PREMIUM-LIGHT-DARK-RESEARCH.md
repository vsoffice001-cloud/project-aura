## §3 · Decision matrix · light vs dark per PDP section

| Section | Light | Dark | Why |
|---|---|---|---|
| **Hero (top)** | DEFAULT | optional | Editorial-light w/ serif H1 + report cover signals consulting credibility (McKinsey/BCG pattern). Dark only if launching premium tier or single-report theater moment. |
| **Key Stats Strip** | yes | no | Numbers need data ink. Light gives serif/sans contrast room. |
| **Executive Summary** | yes | no | Long-form reading. Light = paper analogue. Eye fatigue on dark for 200+ word blocks. |
| **Market Size chart card** | yes | no | Chart legibility, axis labels, tooltip contrast all suffer on dark. Bloomberg uses dark; most enterprise BI tools use light for reports. |
| **Segmentation** | yes | no | Information-dense. Light. |
| **Competitor Landscape** | yes | optional | Light default for matrix readability. Dark variant viable if it is a "spotlight on top 5 players" moment (theater). |
| **Methodology** | yes | no | Procedural/credibility text. Light = whitepaper. |
| **Future Outlook (forecast)** | yes | optional | Light default for chart. Dark works as "vision/scenario" punctuation if positioned narratively. |
| **Final CTA block** | optional | DEFAULT | Conversion drama. Dark + Ken red accent + single CTA = Apple/Vercel/Linear pattern. Closes the page w/ punctuation. |
| **Footer** | yes | optional | Editorial-light default. Dark footer acceptable if Final CTA is dark — momentum carry. |

**Rule of thumb:** light for reading/data/credibility. Dark for theater/conversion/single-asset moments. Ken's product is text + data; light dominates. Dark used as 1-2 punctuation moments per page max.

## §4 · Cross-cutting premium principles

1. **Typography hierarchy** — premium pages use 2 weights max in hero (bold display + regular body). No 4-weight stacks. Size + weight, not color, drives hierarchy.
2. **Breathing room** — every premium ref shows generous vertical padding. Hero takes 70-90vh on desktop. Section spacing ≥ 96px desktop, 64px mobile.
3. **Trust placement** — logos/stats/quotes belong BELOW the H1+CTA, not floating in the hero corner. McKinsey/Notion put stats in the hero footer band.
4. **Motion** — entrance fades only (no slide-ups w/ bounce). Scroll-driven parallax used SPARINGLY (Apple, Linear). Hover micro-interactions on CTAs (slight scale or color shift) — never glow pulses.
5. **Asset quality** — every premium ref uses either (a) no asset, (b) real product screenshot, or (c) editorial photography. Never stock photo. Never generic illustration.
6. **CTA hierarchy** — max 2 CTAs in hero (primary solid + secondary outline/text). Stripe Payments, Figma Enterprise show 1 CTA. Repeated CTA at bottom of page, not mid-page.
7. **Information architecture** — H1 ≤ 10 words. Sub ≤ 25 words. Body block ≤ 80 words. Then visual break.
8. **Color discipline** — premium = neutral surfaces + ONE accent color. Ken red used ONLY on CTAs + 1 inline emphasis token per section. Never on backgrounds.
9. **Editorial vs functional cues** — serif H1 = "we are publishers/researchers" (McKinsey, BCG). Sans H1 = "we are product/tool" (Stripe, Linear). Ken should mix: serif on hero/exec-summary/insight cards, sans on data/methodology/CTA.

## §5 · Anti-patterns to avoid

- Purple-pink rainbow gradients (Stripe homepage 2020, generic SaaS).
- Stock photography (handshakes, smiling boardrooms).
- Glassmorphism backdrop-blur overdone (frosted everything = 2021 cliche).
- Floating screenshot w/ tilted reflection (Stripe-clone fatigue).
- Childish illustrations (Storyset / unDraw look).
- ALL-CAPS SCREAMING CTAS ("DOWNLOAD THE REPORT NOW").
- 3+ CTAs in hero (decision fatigue, conversion drop).
- 4+ font weights in one section (cluttered hierarchy).
- Floating "chat with sales" pill in hero corner (premium products earn the chat, not interrupt).
- Glow blobs everywhere (use sparingly; one focal blob max per section).
- Marquee logo scrollers at high speed (anxious, not credible).
- Numeric counters that animate up on scroll on every stat (theme-park feel).

## §6 · Ken Research per-section recommendation

Given: Ken sells $2,500-$9,000 enterprise reports. Text-heavy, data-heavy, trust + depth = signal. Buyer = strategy/insights director scanning before requesting sample.

| Section | Variant | Why | Closest reference |
|---|---|---|---|
| **Hero** | **LIGHT (editorial)** | Serif H1 ("Australia Cold Chain Logistics Market") + sample-PDF cover thumb on right + 2 CTAs (Request sample · Buy report). Consulting-credibility move. | McKinsey insights + Figma Enterprise asymmetric |
| **Key Stats Strip** | LIGHT | 4 numbers (market size · CAGR · forecast year · page count). Serif numerals + sans labels. Data ink demands light. | Notion Enterprise stats band |
| **Executive Summary** | LIGHT | Long-form 200-400 word reading block. Paper analogue. Serif body OK here (editorial). | McKinsey article body |
| **Market Size chart** | LIGHT | Chart legibility non-negotiable. Light card on light surface, brand-red one-color emphasis on hero data series. | Stripe Sigma data pages |
| **Segmentation** | LIGHT | Information-dense tabbed view. Light. | Linear feature grid (but inverted to light) |
| **Competitor Landscape** | LIGHT | Matrix readability. Light. | Notion 2-col feature blocks |
| **Methodology** | LIGHT | Procedural credibility. Whitepaper feel. | Stripe Atlas process diagram |
| **Future Outlook (forecast)** | LIGHT | Forecast chart. Light for chart. Could be 1 dark "scenario card" inset for theater — defer to craft pass. | — |
| **Final CTA** | **DARK** | Conversion theater. Single CTA (Request sample) + Ken red. Dark closes the page with weight. | Linear footer CTA + Apple Vision Pro CTA |
| **Footer** | DARK | Carry the Final CTA momentum. Dark footer w/ light text + accent links. | Vercel + Linear footer pattern |

**Net:** ~90% light, ~10% dark. Dark reserved for closing 2 sections (Final CTA + Footer). Optional 1-section dark punctuation mid-page (Competitor spotlight or Future Outlook scenario card) — decide at craft-pass step 4.5.

## §7 · Token additions needed in DS

Check `design-system/core-v2/styles/base.css` first; most likely already covered. Additions if missing:

- **`--surface-editorial-light`** — off-white paper bg distinct from pure white card. (McKinsey pattern.)
- **`--surface-cinematic-dark`** — near-black (not pure black). Should exist already per `[data-variant-section="cinematic"]` activator pattern.
- **`--gradient-dark-cta`** — subtle 2-stop gradient for dark CTA section (top-edge tint to flat). Optional.
- **`--shadow-card-editorial`** — soft warm shadow for cards on editorial-light. Different from cinematic shadow.
- **`--accent-glow-red-cta`** — optional faint Ken red glow ring on dark CTA hover. Restrained.
- **`--text-on-dark-muted`** — secondary text token for dark surfaces (white at 60-70% opacity equivalent).
- **`--border-on-dark-subtle`** — 1px hairline border token for dark cards (white at 8-12% opacity equivalent).
- **`--surface-dark-elevated`** — slightly lighter dark for cards on dark surface (Linear pattern).

**Gradient stops** — keep to 2 stops max. No 3+ stop rainbow.
**Glow tokens** — one Ken-red focal glow on Final CTA only. Not section-wide.
**Noise/grain** — optional `--texture-noise-subtle` SVG bg-image at 2-3% opacity for editorial-paper feel. Test on hero only.

All new tokens MUST land in `design-system/core-v2/styles/base.css` unlayered `:root {}` per memory rule (CSS @layer cascade trap 2026-05-13).
