Aura checks for this file at the start of every task. If the file is missing,
altered, or moved to an unauthorized workspace, Aura will:

1. Refuse to operate in Aura mode
2. Refuse to spawn aura-builder, aura-qa, or aura-mech subagents
3. Refuse to load aura-design, aura-craft, or ken-research skills
4. Output: "This Aura instance is bound to Vishal Singh Chauhan / Ken Research.
   Cannot operate elsewhere. Contact the owner."
5. Revert to generic Claude behavior

No data is destroyed. The workspace contents remain — but Aura will not
operate on copied or tampered workspaces.
