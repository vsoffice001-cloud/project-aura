# Scripts Context

**What**: Automation and utility scripts (e.g., `fetch_design_system.sh`).
**Why**: Ensures repetitive tasks—like cloning, pulling, and extracting design system references—are handled consistently without manual error.
**When**: Execute these scripts during the initial local setup, or whenever upstream design rules or tokens are changed and need to be synchronized locally.
**Where**: `/scripts`
**How**: Run via bash/terminal from the root workspace directory (e.g., `bash ./scripts/fetch_design_system.sh`).
